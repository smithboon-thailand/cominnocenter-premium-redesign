# UI Components & Design Tokens Outline

**สำหรับใช้ใน Figma Design System**

---

## 1. Color Tokens (สรุป)

| Token | Hex | การใช้งานหลัก |
|-------|-----|---------------|
| `pink-500` | `#DE5C8E` | Primary CTA, Accent |
| `pink-100` | `#F8E1EA` | Soft background |
| `blue-700` | `#002D73` | Headings, Navigation |
| `blue-100` | `#E8EEF7` | Soft blue background |
| `neutral-50` | `#F8F5F2` | Page background |
| `neutral-900` | `#121212` | Body text / Dark headings |
| `white` | `#FFFFFF` | Cards, pure surfaces |

---

## 2. Typography Scale (แนะนำ)

| Level | Size (Desktop) | Weight | หมายเหตุ |
|-------|----------------|--------|----------|
| Display | 56–68px | Bold / SemiBold | Hero |
| H1 | 40–48px | SemiBold | หน้าหลัก |
| H2 | 32px | SemiBold | Section |
| H3 | 24px | Medium | Card title |
| Body | 17–18px | Regular | เนื้อหา |
| Small | 14–15px | Regular | Caption / Meta |

**ฟอนต์แนะนำ**:
- English: Suisse Int’l / Neue Haas Grotesk / Satoshi
- Thai: Sarabun หรือ IBM Plex Sans Thai

---

## 3. Core Components ที่ควรสร้างใน Figma

### Buttons
- Primary (Pink)
- Secondary (Blue outline หรือ Blue solid)
- Text / Ghost button
- Sizes: Large / Medium / Small

### Cards
- Expertise Card
- Impact / Case Study Card
- Team Member Card
- Objective Card

### Navigation
- Desktop Nav
- Mobile Menu
- Language Switcher

### Form Elements
- Input
- Textarea
- Select / Dropdown
- Submit Button

### Others
- Section Header
- Tag / SDG Badge
- Divider
- Footer

---

## 4. Spacing System (แนะนำ)

ใช้ระบบ 4pt หรือ 8pt:
- 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px

Section padding แนวตั้งแนะนำ: 96–120px บน Desktop

---

## 5. Elevation & Shadow

- Card default: เงาเบามาก (y: 4–8px, blur: 16–24px, opacity ต่ำ)
- Card hover: เงาชัดขึ้นเล็กน้อย + ยกขึ้น
- ห้ามใช้เงาหนักหรือหลายชั้นเกินไป

---

## 6. Border Radius

- Button: 8–10px
- Card: 12–16px
- Image: 12px หรือตาม design
- Input: 8px
